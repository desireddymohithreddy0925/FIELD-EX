The Agro-Export Problem

  • Perishability & Spoilage: High-value horticultural exports face 20-30% loss due to unmonitored cold-chain excursions.
  • Commercial & Quality Disputes: Buyers overseas reject shipments due to lack of verifiable pre-shipment quality logs (Brix, firmness, defects).
  • Export Documentation Friction: Manual processing of Phytosanitary Certificates, Bills of Lading, and Origin docs delays port clearance.
  • Operational Silos: Disconnected communication between procurement, packhouses, QC labs, and overseas buyers creates costly blind spots.

The FIELD-EX Solution

A unified, role-governed digital operating system bridging farm-gate procurement to international port delivery.

Business Logic: Deterministic State Machines

All core transactions are governed by deterministic finite state machine services:

  • B2B Order Lifecycle: REQUESTED ➔ CONFIRMED ➔ PROCESSING ➔ PACKED ➔ IN_TRANSIT ➔ DELIVERED
  • Strict Transition Authority: Only ADMIN and MANAGER can confirm or cancel orders; EDITOR is restricted to catalog management.
  • Quality Gate Lock: Orders cannot progress to packaging or dispatch without verified QC laboratory approval.

Enterprise Security & Integrity

  • Defense in Depth: Method-level authorization via @PreAuthorize on 16+ controller endpoints.
  • Concurrency Protection: Optimistic locking (@Version) prevents double-allocation of pallet lots under high traffic.
  • Immutable Audit History: Hibernate Envers captures every record revision, actor ID, and timestamp.
  • Automated DB Migrations: Liquibase ensures reproducible schema deployments across dev, test, and production.
